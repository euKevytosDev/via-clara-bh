# ViaClara BH

Landing page educativa da **Mobilidade e Cia** com simulador inteligente de rotas para Belo Horizonte.

Projeto acadêmico — UPx 1 (Cidades Inteligentes) · Centro Universitário Newton Paiva.

## Stack

- Vite + HTML/CSS/JavaScript
- Leaflet.js + OpenStreetMap/CARTO
- GitHub Pages

## Scripts

```bash
npm install
npm run dev
npm run build
npm run deploy
```
